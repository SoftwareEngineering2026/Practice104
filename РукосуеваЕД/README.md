# Лабораторная работа №104. Docker

**Выполнила:** Рукосуева Е.Д.

## Цель работы

- Познакомиться с Docker.
- Изучить некоторые базовые команды Linux.

## Ход работы

Задание выполнено путём автоматизации всех требуемых шагов в скрипте
[`run.sh`](run.sh), который запускается внутри контейнера, собранного из
[`Dockerfile`](Dockerfile). Образ собирается на базе минимального образа
**alpine**, в котором отдельным шагом устанавливается **bash** (в alpine
он не входит в базовый образ), после чего все дальнейшие действия
выполняются именно в bash.

Скрипт `run.sh` выполняет:

1. Создание файла `РукосуеваЕД.txt` в домашнем каталоге (`~/`).
2. Вывод текущей даты и дня недели командой `date`.
3. Вывод расширенной информации о файле `/bin/bash` (`ls -l` и `file`).
4. Скачивание текста "Lewis Carroll. Alice's Adventures in Wonderland"
   (`http://www.lib.ru/CARROLL/alice.txt`) командой `wget`/`curl` с
   сохранением сразу под именем `alice.txt`.
5. Подсчёт количества слов в `alice.txt` командой `wc -w`.
6. Вывод первых 19 строк файла (`head -n 19`) и последних 17 строк
   (`tail -n 17`).
7. Создание каталогов `test1`...`test40` (`mkdir`).
8. Удаление каталогов, номер которых оканчивается на `3` или `7`
   (`rmdir`/`rm`).
9. Сохранение списка оставшихся каталогов в файл `test.txt` и вывод
   количества строк в нём (`wc -l`).
10. Создание файла `date.txt` с текущей датой в формате `ГОД-МЕСЯЦ-ДЕНЬ`
    в каталогах, номер которых кратен 5.
11. Дописывание текущего времени в `date.txt` в каталогах, номер которых
    кратен 10.

## Ответы на вопросы отчёта

**Что представляет собой файл `/bin/bash`?**
Это исполняемый бинарный файл (ELF-файл) — сама программа командного
интерпретатора bash, а не текстовый скрипт и не симлинк. Команда
`file /bin/bash` показывает тип файла (динамически линкованный
исполняемый файл ELF для соответствующей архитектуры), а `ls -l /bin/bash`
— его права доступа, владельца и размер.

**Какой день недели выводит команда `date`?**
Зависит от даты сборки/запуска контейнера — конкретное значение видно
в выводе `date` в логах контейнера (см. раздел "Как запустить" ниже).

## Как запустить

```bash
docker build -t rukosueva-docker-lab .
docker run --name docker-lab-104 rukosueva-docker-lab
```

Весь отчёт (вывод всех команд по шагам задания) печатается в stdout —
его можно посмотреть командой:

```bash
docker logs docker-lab-104
```

Контейнер после выполнения скрипта не завершается, поэтому созданные
файлы и каталоги можно проверить, подключившись к нему:

```bash
docker exec -it docker-lab-104 bash
ls ~/
cat ~/test.txt
```
