# Лабораторная 4. Docker и Linux

Автор: Скляров Константин Александрович, группа РИМ-150975к.

Цель: освоить Docker и базовые команды bash в Linux-контейнере.
Образ Alpine 3.22 содержит bash, curl, coreutils и file. Скрипт run.sh выполняет
все команды задания: создаёт СкляровКА.txt, выводит день недели и сведения о bash,
скачивает alice.txt с указанного URL, подсчитывает слова, выводит первые 19 и последние
17 строк, создаёт каталоги test1–test40 и удаляет каталоги с окончаниями 3 и 7.
Остаётся 32 каталога. В каталогах с номерами, кратными 5, сохраняется дата;
в кратных 10 добавляется время.

`/bin/bash` — ELF-файл исполняемого командного интерпретатора Bash; сведения о
разрядности и динамической линковке получены командой file и сохранены в журнале.

## Воспроизведение

```sh
docker build --build-arg STUDENT=СкляровКА -t lab04 .
docker run --name lab04-session -d lab04 sleep infinity
docker exec -it lab04-session sh
bash
bash /usr/local/bin/run-lab
```

Для запуска без интерактивной оболочки: `docker run --rm lab04`.
Сборка и выполнение скрипта через docker exec реально прошли на Ubuntu runner
GitHub Actions: https://github.com/dyda5505-cloud/textlab-course/actions/runs/37193914473. Журнал: execution.txt.
Вывод: образ воспроизводит окружение, bash автоматизирует операции с файлами,
Docker exec выполняет команды в работающем контейнере.
