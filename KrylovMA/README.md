# Practice104

## Цель работы
Познакомиться с Docker, изучить некоторые базовые команды Linux.

## Выполненные шаги
1. **Создание Docker-образа** на основе `ubuntu:22.04`.
2. **Установка необходимых утилит** (`wget`, `file`, `bash`) в образе.
3. **Написание Bash-скрипта**, выполняющего все требуемые действия:
   - создание файла с фамилией и инициалами;
   - вывод текущего дня недели;
   - анализ файла `/bin/bash`;
   - скачивание текста «Алисы в Стране чудес»;
   - работа с текстом (подсчет слов, вывод первых/последних строк);
   - создание, фильтрация и удаление каталогов;
   - запись даты и времени в файлы.
4. **Сборка образа** и **запуск контейнера**.
5. **Проверка результатов** в интерактивном режиме.

## Что из себя представляет файл `/bin/bash`?
Файл `/bin/bash` — это исполняемый файл в формате ELF (Executable and Linkable Format). Он является интерпретатором командной оболочки Bash (Bourne Again SHell). Когда пользователь запускает терминал или выполняет скрипт с `#!/bin/bash`, система загружает этот файл в память и передаёт ему команды для выполнения. Вывод команды `file /bin/bash` подтверждает, что это 64-битный исполняемый файл для архитектуры x86-64.
