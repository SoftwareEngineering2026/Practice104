Цель работы:

Познакомиться с Docker и изучить базовые команды Linux.

Ход работы

Был создан Docker-образ на базе Ubuntu 24.04.

В контейнере автоматически выполняются следующие действия:

создаётся файл LysykhVA.txt;
выводится текущий день недели;
выводится расширенная информация о файле /bin/bash;
скачивается файл alice.txt;
подсчитывается количество слов в файле;
выводятся первые 19 и последние 17 строк файла;
создаются каталоги test1–test40;
удаляются каталоги, имена которых оканчиваются на 3 и 7;
создаётся файл test.txt со списком каталогов;
подсчитывается количество строк в test.txt;
в каталогах, номера которых кратны 5, создаётся файл date.txt с текущей датой;
в каталогах, номера которых кратны 10, в файл date.txt добавляется текущее время.
